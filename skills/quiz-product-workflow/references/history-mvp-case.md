# 历史人格 MVP：复盘与迁移地图

整理日期：2026-10-10。来源为“分析历史原型问卷竞品”对话（01a0f1bb-3fc2-7e32-ac4e-8b59c3f421fc）、当前插画/部署对话，以及项目源码与文档。对话用于还原决策，当前代码与验收文件用于核实最终状态；旧描述不自动视为现状。

## 过程与得到的方法

1. **研究竞品完整闭环。** 多轮作答观察分数、人物和固定文本的关系，检查刷新与分享，另看商品页的价格、销量口径和交付承诺。学到的是产品机制与验证方式，不迁移他人原题或文案。没有试购就不能宣称付费交付已验证。
2. **用任务书定义可运行 MVP。** React + TypeScript + Vite，24 人、72 题，每轮 30 题；原创维度权重、主/隐藏原型、可恢复答题与独立分享卡。先完成真实闭环，再优化体验。
3. **检查模型而非只展示结果。** 使用 100,000 组合法随机答题，24 人均可达，最高占比约 11.348%；保留各人物的答案见证。改一题主标签约 67.68% 不变、主/隐藏至少一个延续约 90.18%。这些是本模型的工程观测，不是用户重测信度。
4. **纠正报告语境。** 用户指出“本轮相对靠前”等成绩单语言破坏代入感。改为直接“对你说”，以具体选择与内在张力展开；规则、逐项数字与出处按需展开。检查 24 份报告及 552 种有序组合文本，后者不代表组合全部可达。
5. **统一页面与结果视觉。** 首页、列表、揭晓与分享卡一起设计；验证四字姓名、宽道具、窄屏裁切、字体粗细和深浅背景。旧几何/SVG 形象后来被真实生成位图替换，不能把中间产物当最终美术规范。
6. **以样图校准后扩充插画。** 本次内置 image_gen 完成 24 人，保留原图、提示词、透明 PNG 和网页 WebP。网页素材 800×1120，保留安全空间，通过姿态和器物区分角色。旧会话工具不可用是当时的环境事实，不约束将来的会话。
7. **先上传，再单独部署验收。** GitHub 仓库不是网站地址。配置 Pages 子路径和仅手动触发的工作流；用户启用并运行后，核实部署成功、首页 200、全部 24 张图片加载正常。当前线上验证没有重新证明所有真机保存流程。

## 当前模块迁移地图（相对源项目根目录）

| 现有文件 | 可复用内容 | 换主题需要处理 |
|---|---|---|
| src/app/App.tsx；src/pages/Test/Test.tsx | 状态旅程、答题交互 | 主题配置、未知选项行为 |
| src/store/session.ts | 合法性校验、恢复 | 增加主题隔离与题库版本 |
| src/data/sampler.ts | 带种子的抽样思路 | 不照搬现代/历史比例 |
| src/types.ts；src/data/dimensions.ts | 类型约束 | 目前八维写死，不是通用模式 |
| src/data/questions.ts | 题目结构参考 | 所有情境与权重定制 |
| src/data/characters.ts | 结果字段组织 | 人物字段不适合关系信号产品 |
| src/scoring/* | 归一化、距离、第二原型 | 仅适合对应模式，阈值需重审 |
| src/report/* | 叙事组合与条件片段 | 独有文案、强弱与边界规则 |
| src/pages/Result/Result.tsx | 章节阅读节奏 | 不是每款产品都要 13 章 |
| src/components/ReportInfo.tsx | 按需说明与焦点恢复 | 说明内容与不确定性表述 |
| src/share/* | 独立海报、下载与降级 | 新主题排版、隐私与真实回流 |
| src/theme/*；src/components/Portrait.tsx | 主题变量与图片容器 | 视觉方向、字体与素材 |
| tests/*；scripts/simulate-results.ts；scripts/stability-test.ts | 验证方法 | 结果数、维度、分支与阈值 |
| .github/workflows/pages.yml | 手动部署流程 | 仓库名、base、授权与站点配置 |

源项目运行 `npm test`、`npm run build`。计分变更再跑 `npm run simulate` 与 `npm run stability`。`npm run audit:content` 依赖只在本地保留的研究资料，不是任意新克隆都可用的 CI 命令；新项目应定义自己的内容审计输入。

## 尚未解决、不能包装成模板能力的部分

- 本模型未做真实人群常模与心理测量信效度研究。
- 史料仍有 TODO: FACT_CHECK；有出处线索不等于完成正式审校。
- 部分早期文档仍写占位插画或系统字体，和后续生成素材、自托管标题字体不同。迁移时以代码和素材清单为准。
- 当前没有支付、订单或服务端权益；前端访问码仅演示。
- 分享卡预留了回流字段，不能假定已具备可扫描二维码和归因系统。
- 模拟移动浏览器验收不等于真实 iOS、Android 和平台内 WebView 保存成功。
- 这里只提炼了模块边界，没有把现有产品重构成配置驱动的多主题平台。

推荐下一款先做文学原型或职业偏好：前者验证主题数据替换，后者验证多轴输出。若选择暗恋主题，应直接采用证据分流，不能为了复用代码保留不合适的人物距离模型。
