# 五类主题适配方案

以下为产品设计样例，未经过人群校准，不是可直接上线的完整题库。每个主题都需要自己的合法答案见证、边界报告与用户试读。

## 文学人物原型

- 承诺：借文学人物理解自己的动机与处境；不需要文学知识答题。
- 模式：原型匹配。示例维度：自主选择、秩序需求、关系投入、想象探索、行动方式。维度端点先定义，避免“理性/感性”覆盖过多含义。
- 结果：人物 + 对应作品/版本 + 核心张力 + 与你相似的选择 + 不同处境下的侧面。不同人物即使同样勇敢，也要区分为认可、自由还是保护关系而行动。
- 示例题：你认真筹备的计划被临时改变，最先想做什么？A 重新安排，让参与者有清楚的下一步；B 先问清每个人受到的影响；C 留出空间试一条原本没考虑的路；D 先守住自己最在意、不愿放弃的部分。分别观察组织、联结、探索、自主，正式权重由全套定义决定。
- 报告替换：历史映照 → 作品情境的共鸣；史料说明 → 作品出处与解读版本。避免剧透可设置展开阅读。
- 验证：相近人物区分、作品事实与原创投射分离、不把悲剧人物匹配写成命运预测。新插画与引用需确认可用范围，不直接搬运影视角色海报。

## 职业原型

- 承诺：探索偏好的任务与协作环境，不宣称测出唯一适合职业。
- 模式：多轴偏好画像，可附“探索型建设者”等工作方式标签；职业实例是可选联想，不是就业结论。
- 示例维度：任务结构偏好、探索/维护、独立/协作、人与系统、稳定/变化。兴趣、经验与能力另记，不能混为一分。
- 示例题：面对两周的空档，你更愿意承担哪种任务？A 调查一个还没定义清楚的问题；B 把现有流程改得更顺畅；C 与不同人沟通并促成一致；D 独立完成一件可展示的作品。补充“未经历过”时降低该轴解释强度，不扣分。
- 报告：投入感来源、耗能环境、合作方式、值得试的任务、一次低成本探索。若用户要求具体转行、薪资或职业前景，另做当时资料研究，不让娱乐分数替代真实职业分析。
- 验证：无工作经验者也可答；排查把“资源多/职位高”等同于能力强；不用于招聘筛选或淘汰。

## 暗恋测试：TA 是不是也在偷偷喜欢你

- 承诺：帮你整理互动信号与不确定之处，不能确定对方是否暗恋。
- 模式：证据分流。把观察完整度、主动性、持续性、情境特异性、双方舒适边界分开。没有可观察材料时正常输出“还不足以判断”。
- 示例题：最近四周，除工作/学习必须联系外，TA 是否主动开启过与你的交流？A 多次，在不同日期发生；B 偶尔有一次；C 有足够接触机会，但没有观察到；D 接触太少或记不清。D 是未知，不能按 C 处理。即使 A 也可能是友好，不能单独判定喜欢。
- 结果：信息不足；主要由具体情境维系；出现持续主动联系；信号混合。分支名称用于叙述观察，不组成“爱情等级”。一条强信号不盖过明确拒绝；明确边界优先导向尊重边界的建议。
- 报告：你观察到什么 → 可能的不同解释 → 尚缺什么 → 可以怎样自然沟通。写“这让你值得留意”，不写“TA 故意冷落你因为太喜欢你”。
- 不收集姓名、私密聊天截图和第三方联系方式作为默认输入。不建议监控、试探施压或在拒绝后继续追求。分享卡展示自己的观察体会，不替对方公开表白。
- 验证：全未知、单次友好、持续互动、混合证据、明确拒绝；逐个确认不会输出伪概率或把负面信号美化成暗恋。

## 你的心理年龄

- 承诺：用年龄意象讨论当下的生活心态，明确是娱乐性表达，不测真实认知年龄。
- 模式：优先采用多轴“生活心态画像”，如探索兴致、责任节奏、应变方式、休息需求。不要把成熟设成单轴高分，更不要把年龄大等同于优秀。
- 示例题：周末计划突然取消，你通常先做什么？A 趁机试一个新地方；B 把拖着的小事处理掉；C 找个舒服的方式休息；D 看看朋友是否需要陪伴。观察当下偏好，不把选项直接映射成 18/30/50 岁。
- 报告：你在哪些情境保留新鲜感、在哪些事情上想要稳定、什么让你耗能。若坚持数字/区间，先明示是主题标签，再说明编辑性映射，不输出精确到岁月的“测量值”。
- 验证：休息不等于衰老、承担不等于高贵、探索不等于幼稚；儿童或成年受众分别设计情境，不用相同年龄常模暗示科学性。

## 你有什么天赋

- 承诺：发现值得尝试的优势线索，不鉴定先天能力。
- 模式：偏好与行为证据画像。示例方向：表达组织、模式发现、人际理解、实践搭建、持续打磨。自评意愿与已有成果分开。
- 示例题：过去三个月，你在哪类事情上比较容易持续投入？A 把复杂内容讲清楚；B 从资料中找到规律；C 帮人理解彼此的想法；D 反复试做，直到东西能用；E 没有足够机会判断。E 进入探索建议，不解释成“没有天赋”。
- 报告：你可能容易投入的方式、已见线索、暂未确定之处、一个七天小实验、如何观察反馈。用具体任务验证，例如制作一分钟解释视频并收集理解反馈，而非“天生适合当主播”。
- 验证：机会差异与能力区分；多种线索并存时保留组合；不因为低分给出“没天赋”的否定身份。

## 同一骨架到底换哪些内容

| 模块 | 文学原型 | 职业/天赋 | 暗恋信号 | 心理年龄主题 |
|---|---|---|---|---|
| 答题、恢复、分享交互 | 可复用 | 可复用 | 可复用，增强未知选项 | 可复用 |
| 维度与题库 | 全部定制 | 全部定制 | 换成观察证据 | 全部定制 |
| 匹配与次原型 | 校准后复用 | 可选标签，不强制 | 不复用人物距离 | 通常无需 |
| 报告章节 | 文学共鸣 | 环境/行为/小实验 | 观察/解释/沟通 | 情境心态与节奏 |
| 插画风格 | 随作品世界 | 随品牌与场景 | 避免宣称他人内心 | 避免年龄刻板印象 |
| 额外边界 | 出处与版本 | 非能力认证 | 非读心，尊重边界 | 非认知年龄测量 |
