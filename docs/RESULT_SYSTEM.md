# 报告叙事与说明入口

报告的阅读对象始终是“你”。正文写感受、选择、行为习惯和历史人物带来的共鸣；规则只负责在后台选择内容，不把计算过程翻译成报告段落。

## 内容层

- `characterNarratives.ts`：24 个人物各自的相逢理由、隐藏侧面、组合心意、历史映照。全部采用直接对读者说话的语气。
- `textRules.ts`：按八种倾向及强弱选择生活片段、三重底色与组合收束。复合底色关联两个明确倾向，避免重复使用同一底色。均衡、保留、情境变化的画像有自己的叙述，不把相对高位写成卓越能力。
- `reportGenerator.ts`：组合人物叙事、生活片段与真实选择证据。接口保留确定性输出；没有在线模型调用。
- 人物基础数据：驱动力、优势、关系、工作与日常侧写继续逐人维护。工作段落采用“你怎样投入与合作”的分析语境；建议章节才使用行动建议。

“为什么是 TA”连接人物心意与生活中的你；“隐藏原型”直接写另一份心意，不用数值差异生造内外反差。双人物段落同时提及两个人物，并按回答选择收束内容。辛弃疾与郑和在相关倾向明确时，使用词与剑、海与帆的独立组合叙事。

正文不出现分数、阈值、距离、排名、模型设定或“本轮相对靠前”等成绩单口吻。生活片段与三重底色分开撰写，避免整段重复。“回看你当时的选择”仍展示本次真实答案，不虚构读者说过的话。

## 阅读体验

保留人物接近度与雷达图。八维具体数值收进图表标题旁的小感叹号按钮。规则、原型边界、史料出处与待校读状态、日常想象说明、隐私信息均通过相关说明按钮按需打开，正文不重复摆放说明块。

`ReportInfo` 使用原生 `dialog`，只在点击时挂载。支持触屏、键盘、关闭按钮、Escape 与点击遮罩；关闭后焦点回到原按钮且不改变阅读位置。浮层有可访问名称，移动端限制宽高，长说明可滚动。

历史章节正文连接史料线索与读者的日常心意。完整史料段落、出处、待审校标记与编辑解释保留在该节说明中；原创比喻不署为历史人物名言，不暗示前世或血缘。

## 与计算层的关系

本次只调整叙事与呈现，不改变抽题、归一化、距离、人物向量、主／隐藏人物选择或接近度。保持 `MODEL_VERSION`，已保存的测试可以直接生成新文案，不要求重新答题。

底色内部仍按强弱选择不同语气：单维分段为 60、45，复合片段需要两项均达到 60 且在前三项中。均衡判断使用八维整体极差小于 8，避免把只有前三项接近的画像误写成全面均衡。以上为开发说明，不进入报告正文。

## 验证

`tests/report.test.ts` 覆盖：

- 24 组现有完整答题记录，核对主／隐藏人物和八维数值保持一致。
- 552 种主／次人物有序组合的文案组装；这是内容组合覆盖，不声称每一种都能实际匹配到。
- 均衡、保留、情境变化及分段边界的语气。
- 正文没有算法语言、数字插值或第三人称“用户”视角；选择证据真实；底色、建议不重复。

浏览器检查使用独立测试会话，恢复已有有效答案检查全部人物报告，再对说明浮层、窄屏、桌面与可访问性做交互核验。
