# 产品与实现边界

工作名为人生原型实验室，首款产品为历史人格原型。用户获得的是自我探索的观察角度，不是诊断、预测、职业或婚恋判断。

## 已实现旅程

首页 → 可选演示访问码 → 30 道四选一 → 2.6 秒整理仪式 → 主原型揭晓 → 13 章个人侧写 → 隐藏原型与组合解释 → 分享卡预览 → PNG 下载／系统文件分享／长按保存提示 → 新一轮抽题。

题目选中后 380ms 前进；动画期间锁定其他选项，避免连续点击跨题。可回到上一题改答，计算从全部最终答案重建。刷新恢复题序、选项序、回答、当前位置与生成／结果阶段。

报告采用直接对读者说话的叙事，具体数值、规则与史料说明通过小感叹号按钮按需打开。已保存答案继续使用原有匹配结果，刷新即可获得更新后的文案。详细约定见 [结果系统](RESULT_SYSTEM.md)。

## 数据与隐私

`archetype-lab:session:v1` 保存当前测试，包含版本、模型版本、session ID、抽题种子、30 个题目 ID、逐题选项顺序、答案、阶段与题号。读取时验证数据，不兼容或损坏记录回到可开始的首页。存储不可用时保持内存体验并提示不要关闭页面。

本机事件最多保留 500 条。事件只有题号、人物 ID、动作等元数据；不向服务器发送。网页无姓名、生日、电话和性别输入。

`landing_view`、`test_start`、`question_answer`、`test_complete`、`result_view`、`report_bottom_view`、`share_card_generate`、`share_card_save`、`restart_test` 均有统一接口。下载事件只能证实请求下载，不能证实用户最终保存到相册；后续统计必须按 `method` 区分。

## 合理假设

1. Demo 默认不需要访问码；可通过环境变量启用，测试码默认 1024。
2. 全部人物参与匹配，不收集或过滤用户性别。
3. 结果仅保留当前一轮；新测试替换记录，不会删除已下载文件。
4. 使用系统中文字体，避免依赖第三方在线字体和大体积字体下载。
5. 插画为原创抽象人物意象，每人独立文件、构图变化与主题，后续通过数据字段替换。
6. 首版提供完整网页报告和独立海报 PNG；不增加整份报告图片导出。
7. 生成仪式只说整理选择与寻找原型，不声称在线 AI。

## 视觉

设计解读：面向愿意分享自我观察的年轻用户，以现代东方、纸张和文化编辑排版为主。首页使用错位的人物意象卡；报告以章节、留白和文字层次组织。设计参数为 variance 6 / motion 3 / density 4。原生 CSS 为原创主题实现，不仿冒现有设计系统。

首页应用 design-taste-frontend 的营销页面指导；答题流程使用清晰的单题表单模式。品牌纸白与墨绿来自任务书的文化海报方向，中文宋体用于名字和标题，系统黑体用于按钮与正文。卡片和按钮统一 6px 圆角；结果图以人物数据的主题色切换。支持系统深色与减少动态效果设置。层级变量：导航 10、固定操作 20、原生 dialog 30。

## 上线前仍需的工作

正式史料审校、用户试测与题目语义校准、正式人物资产、真实手机与小红书 WebView 验收，以及服务端订单权益。当前源码中的前端码、localStorage 和分享占位入口均不能代替生产鉴权、数据库或归因服务。
