# 计分模型 original-1.0

## 八维与归一化

顺序：行动决断 decision、系统洞察 insight、创新探索 exploration、共情联结 empathy、表达创造 expression、组织掌控 organization、自主边界 autonomy、责任韧性 resilience。

每题四选一，每个选项同时影响三个不同维度。先累加最终答案。对本轮抽到的每题，未提及的维度权重按 0 处理，再将四个选项的最小值与最大值分别累加：

```text
raw[d] = sum(selectedOption.weights[d] ?? 0)
min[d] = sum(min(option1[d], option2[d], option3[d], option4[d]))
max[d] = sum(max(option1[d], option2[d], option3[d], option4[d]))
normalized[d] = clamp(100 × (raw[d] − min[d]) / (max[d] − min[d]), 0, 100)
```

若区间为零，返回 50（当前均衡抽题不触发）。缺答案或不存在的选项直接拒绝计算。匹配用未取整值，显示取整。它不是用户内部 min-max，不要求出现最低 0 或最高 100；也不是人群百分位或能力值。

强制选择仍会造成维度相关。这个公式不能消除社会赞许偏差、情境理解偏差或代偿关系；未做真实人群常模、信效度验证。

## 人物向量

人物方向由任务书的人格约束和原创内容人工设定。将各人的方向向量 u 映射为 `50 + 32 × u / ||u||`，保留三位小数。所有人物到中心约为同一半径，避免某个靠近中心的条目因为长度短而系统性胜出。

这不是从历史人物真实回答中训练所得，也没有将随机模拟的频率强行拉成均匀分布。方向、半径与阈值都属于可审查的产品模型参数。每人独立向量，最小相邻距离及可达性见报告。卓文君方向突出自主与生活选择，补入联结和持续性，与李白更强的探索及表达外放区分。

## 距离与接近度

```text
distance = sqrt(sum(((user[d] − character[d]) / 100)²) / 8)
closeness = round(100 × exp(−(distance / 0.22)²))
```

选距离最小者为主人物。精确同分按稳定的 ID 顺序；不额外抽签。0.22 是明确的显示曲线参数，不是统计校准量。距离为 0 时为 100%，距离 0.5 时已低于 1%；没有 80% 或 90% 的下限。随机试验分布直接公开。

相同题目与相同最终选项产生相同结果。仅有相同 A/B/C/D 序列，但题组或选项顺序不同，不构成同一回答。

## 隐藏原型

按距离排名排除主人物，优先在与主匹配距离差不超过 0.045 的候选中，选与主向量距离至少 0.095 的最近人物。这样不会为了差异而强行挑一个很远的人。如果不存在，使用距离第二名，并标记为相邻侧面。

从八维中寻找“相较主人物，次人物更接近用户”的绝对误差改善最多的一维，用作解释线索。改善不足 0.5 分时不声称它揭示了明确的另一面。隐藏原型不是临床概念，也不代表隐藏动机。

## 验证

`npm run simulate`：100,000 次独立随机答题，每轮重新分层抽题。检查 24 人全部命中，任何人物不超过 40%，记录最近相邻距离、分布及真实答案见证。

`npm run stability`：分别 10,000 组改一题、改两题，报告主标签一致、双标签延续与极端位移。另有 24 种合成偏好各 100 次重新抽题。工程阈值不等于心理测量标准；边界人物换位是当前模型明确保留的限制。

修改题目权重或人物方向时，应升级 MODEL_VERSION，重新运行所有报告与真实答题见证，避免旧记录被新算法悄悄解释。
