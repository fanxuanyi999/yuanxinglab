# 24 人物系统

所有人物在 `src/data/characters.ts`，向量由 `CHARACTER_VECTORS` 导出。人物不共用完全相同的向量或报告整套内容。姓名、时代、身份、原型名、副标题、3 标签、驱动力、2 优势、阴影、关系、工作、现代画像、建议、历史镜像与现代解读各自独立。

## 历史内容

每人的历史镜像约 150～250 字，实际长度由内容审计报告检查。历史资料线索与现代解释分为两个字段、两个视觉区域。出处为书名和篇章线索，未添加未经核验的直接引语。

目前全部保留 `factStatus: 'TODO: FACT_CHECK'`，前端显示“这段史料解读仍待逐条校读”。事实与归属存在争议的内容（例如文学人物后世叙述）在文字中保留不确定性。正式售卖前应逐条对照可靠版本和当代研究，记录版本、页码或可靠资源链接后再标为 reviewed。

## 视觉资产

`character.image` 指向 `public/characters/<id>.svg`，`character.theme` 包含 accent/paper/ink/mist。24 个文件由 `scripts/generate-portraits.ts` 生成，各自有颜色、构图参数与轮廓差异，是原创抽象占位图，不是历史复原。

替换正式插画时仅修改数据路径，保持同源或提供允许 Canvas 绘制的 CORS。网页和海报共用人物数据；组件内不写死具体人物图片。
