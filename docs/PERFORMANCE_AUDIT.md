# 加载优化记录（2026-10-13）

## 图片压缩检查

网页加载的是 `public/characters/generated/` 中的 24 张透明 WebP，尺寸均为 800×1120，合计 1,370,680 字节。原始 PNG 保存在 output，不被页面引用。现有制作脚本使用 WebP quality=90、method=6，属于高质量有损编码，不应称为无损。

对全部 WebP 解码后以 lossless=True、quality=100、method=6、exact=True 重编码，并逐像素验证 RGBA 相同，候选文件合计 4,185,402 字节，没有任何一张变小。因此没有替换或再次有损压缩素材，人物画质、透明度和分享卡素材保持不变。对现有有损图无损重编码也不能恢复此前丢失的信息。

## 本次优化

- 首页三位主视觉立即加载，李白设高优先级。列表与报告次要人物进入视口附近 240px 时才设置图片地址。保留宽高以稳定布局；不支持 IntersectionObserver 时正常加载。
- 结果页及其报告/分享依赖按需下载。首页不再加载结果页代码。
- 前一次子目录构建入口约 415.39 KB / gzip 143.31 KB；本次入口 343.96 KB / gzip 118.20 KB，gzip 减少约 17.5%。结果分包 73.34 KB / gzip 27.57 KB，在进入结果时下载。这是初始资源转移，不是删除报告功能。
