# 72 道原创情境题

数据在 `src/data/questions.ts`。8 个主要观察维度，每维 9 个独立场景。共 44 现代题、28 轻历史题。历史题不要求制度、年代或人物知识；场景包含书铺、茶席、园艺、旅途和书院等日常任务。

每题四个自然语言选项，只有情境和答案出现在答题 UI 中；`focus`、`weights` 和维度词典不渲染为答案标签。每轮单独打乱选项显示顺序，保持选项 ID 与权重绑定。

## 权衡结构

每个场景选定一个主观察维度与两个相关维度。A/B/C/D 在源数据中沿同一情境的权衡连续体分布，分别使用：

```text
主维度 / 伴随倾向 / 权衡倾向
A: +2, +1, −1
B: +1, +0.5, −0.5
C: −1, −0.5, +0.5
D: −2, −1, +1
```

因此每个答案都有正负影响，且影响三个维度。它不是“选 A 只给决断加分”。这个首版结构仍是单题内的有序权衡，不能声称每个单题分别独立测量三种能力。不同题的三个维度配对各异，最终八维由整轮共同形成。

负权重仅表示选择更少体现某种倾向，不是对道德、能力或价值的扣分。四个答案不应被解释为从优到劣。正式试测需检验措辞是否诱导社会赞许、伴随维度赋值是否合理，以及相近题的测量重叠。

## 抽样

每维先取 2 现代 + 1 历史，共 24 题。随机选择六维各补 1 题，其中 2 现代、4 历史。因此每轮恰好 18 现代、12 历史，每维主观察题 3～4 道。按维度轮次交错，再修正轮次边界上的相邻同维题。

固定 seed 得到固定题组，选项顺序另外使用同一 seed 派生的随机源；正式开始时通过 crypto 获取种子。新的测试重新抽样，允许与上次部分重叠，不承诺完全不重复。

## 原创与审计

场景和选项单独创作，未导入竞品题库。`audit-content.ts` 完整读取五份研究资料及其题库数据，检查当前题目、选项与人物大段内容是否出现逐字复用。它不是法律鉴定或语义原创性认证，仍需人工编辑审查。

测试包括 1000 个抽题种子的数量、题目唯一性、维度覆盖、现代/历史比例和相邻规则验证。所有 72 题都有四选项、三个非零维度和负权重。
